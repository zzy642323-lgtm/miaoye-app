# 苹果端

苹果端使用同一份手账前端和秒悟数据库，通过 Safari 添加到主屏幕，独立窗口打开。无需 App Store 上架或苹果开发者付费账号。

在 iPhone 的 Safari 中打开正式访问地址，点分享 → 添加到主屏幕 → 添加。账号、好友关系、公开手账沿用安卓端的同一个云端服务。本机草稿和未同步记录仍属于当前设备，需要通过账号信息中的云端备份同步与恢复。

照片保存通过系统分享面板选择「存储图像」，不提供静默写入苹果照片图库。版本入口检查网页版版本，刷新即可使用新版本，不下载安卓 APK。

构建：`node scripts/build-apple-web.cjs`。脚本从本机忽略的 `.env` 读取公共 URL 和 anon key，并验证 JWT role 为 anon；不允许 service_role 或项目 API key 进入前端。

本地静态构建产物为 `dist/`。正式网页版继续使用原来的完整服务发布方式，保留云接口代理及安卓模型路径。不要发布 `.env`、Android 签名文件或服务端密钥。

验证：49 项测试通过，390 × 844 的隔离浏览器验证首页、我的和本子页面无横向溢出、无脚本错误。尚未进行真实 iPhone Safari 的抠图、系统分享和主屏幕安装验证。

2026-10-21 公网核验通过：正式入口为 https://s7ianzbg94fw.meoo.run/index.html?view=c ，当前版本 1.0.16。页面、版本接口、云连接、登录服务及模型路径正常，未登录请求不能读取好友手账。秒悟编辑器沙箱预览未同步；此地址为已发布的公网服务。

## 小体积服务发布

运行 `node scripts/prepare-remote-web.cjs`，随后进入 `.sites-runtime/meoo-web-thin` 执行 `meoo deploy --runtime image --skip-push --force --project s7ianzbg94fw`。发布工具要求秒悟 CLI 0.5.6 或更新版本。

构建脚本从 `scripts/web-assets.json` 中的自有秒悟地址取回静态资源，逐个检查大小和 SHA-256 后才允许构建成功。素材存储桶为 `miaoye-web-assets`，与用户照片的私有存储桶分开。只上传约 223KB 的页面和服务代码，避免重复上传约 47MB 的完整资源包。取回过程限制并发，并对 HTTP 429 和服务端临时错误等待重试。

素材变更时，应先发布对应静态文件并更新资源清单；不要修改校验值来跳过校验。此流程不迁移数据库、不同步用户记录，也不更改账号或好友关系。
