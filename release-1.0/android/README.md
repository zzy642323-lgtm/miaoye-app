# 喵页安卓本机测试版

Android 8.0 及以上，包名 `com.miaoye.journal`。APK 把网页、开屏漫画、字体和贴纸打包在本机，通过 Android WebView HTTPS 虚拟来源加载。主界面、本机存储、批量选图、调色、排版、文字、猫咪、日历和 PNG 导出无需 ChatGPT 账号。

离线能力：0.10 版直接从安装包读取首页，不申请联网权限。0.17 内置 U²-Net small 模型与 ONNX Runtime Web WASM，本机自动识别主体，无需联网；复杂边缘可手动擦除、恢复和修边。安卓本机版暂未开放云同步服务，不使用 ChatGPT 登录，也不包含网页用户的记录。照片通过系统照片或文档选择器导入，PNG 通过系统保存对话框导出。相机按钮调用系统相机，并通过临时 JPEG 内容 URI 接收拍摄结果。

使用本机 `.sites-runtime/android-tools` 中的官方 Google Android Build Tools 35 / Platform 35 与 Adoptium Temurin JDK 21，运行 `./android/build.ps1`。没有安装系统服务，也不修改系统 PATH；环境变量仅在构建进程生效。编译直接使用 javac、d8、aapt2、zipalign、apksigner。

测试 APK 使用本机生成的测试签名，密钥保留在忽略目录 `.sites-runtime/android-tools/miaoye-test.keystore`；升级本机测试版需保留相同密钥。正式发布应另建生产签名。APK 已进行签名/结构校验，不代表已经完成安卓实机测试。

0.6.0：移除碎碎念及好友入口；猫咪小屋支持花园/屋里切换，按手机本地时间与每 30 秒的轻量行为周期活动，点击小猫摸摸。未解锁小猫无法选择。升级保持原包名与签名、版本号递增，可覆盖安装保留本机数据。

0.7.0：五只猫使用不同体型与性格的动作素材，可点击名字修改；猫咪每隔随机 2–3 天在打开应用时送来一篇冒险手账，最新故事作为开屏。好感度每天首次摸摸增加 2，收到故事增加 3。故事与名字保存在当前设备，不提供后台推送。手账本初始上限 3 本，第 4/5 只猫解锁后分别增至 4/5 本；进入本子查看内容。周历展示连续 7 天，续页标题缩小移至左上角。照片支持重新自动抠图、手动擦除/恢复/撤销与放大修边。

0.8.0：猫咪回归平涂色块与蜡笔颗粒画风；首批 5 张 1024×1536 原创完整收藏插画，冒险手账显示一图一短文，支持保存完整 PNG。四种照片边缘：点点、线条、撕纸、无白边；自动与手动抠图保留当前白边类型。一键排版以选中的照片为主图，其他照片围绕，照片比例不变；批量导入每页最多 6 张后自动续页。

## 0.9 测试版
支持手账本改名、可恢复删除、末尾虚影新建入口；首次从五只猫中选择一只，其余猫按 3/8/15/25 张照片解锁。显示各猫陪伴天数，已看故事只在小屋回顾。首页本子排序和封面插画联动、整页缩略图修复、每天第一张照片标记日历、删除多余页面并撤销、白边 4 倍加粗、元素越界裁切。云端操作保留所有权检查，删除本子会收起内容并保留恢复与成长进度。

## 0.10 测试版
点封面直接进入本子，滑动书架切换选中本子，隐藏滚动条。最近的小日子跨本子按最近保存时间排序。安卓首页、字体、插画、抠图、导出均读取本地资源；移除 INTERNET 权限。保持包名、签名与虚拟 HTTPS 来源，可覆盖升级保留数据。构建和静态离线资源校验不代替手机飞行模式实测。

## 0.11 测试版
书架支持循环滑动，选中封面放大，点封面进入本子。首页最多展示 4 篇最近手账，翻翻全部进入完整历史页。本机版按钮提供清空重来：确认后清除本机照片、草稿、本子、成长、故事和开屏状态，再次选择第一只猫；已导出到系统的图片不删除。安卓继续保持离线资源、包名和升级签名。

## 0.12 测试版
领养头像重新绘制干净透明边缘，使用独立 3×2 头像图，纠正头像方形窗口避免露出相邻格。小屋猫咪按解锁顺序排列，已解锁排在前面。新建本子移至管理本子；书架固定创建顺序，选中的本子居中，左右循环仍保留。

## 0.15 本地页面读取修复
Windows aapt2 -A 将 assets 内路径写成反斜杠。Python zipfile 自动标准化路径，使原检查未暴露错误。现由 JDK jar uf0 写入完整 assets，Java ZIP 检查原始路径并读取全部 47 个网页文件；每次构建都必须通过检查后才能发布。Native 页面读取增加 ZIP 备用通道，保留原包名、签名和本机数据来源。尚未进行安卓实机验证。

## 0.16 启动请求修复

0.15 的拦截器将 data: 页面按外网资源返回 403，造成 ERR_HTTP_RESPONSE_CODE_FAILURE。首页改用本地 HTTPS 地址 loadUrl，通过拦截器读取 APK 内资源；data:/blob:/about: 交给 WebView 处理，外部网络请求继续拒绝。保持原 HTTPS origin、包名和签名，覆盖安装不主动清理用户数据。添加启动路由、嵌入照片和外网阻断回归校验；仍未完成安卓实机测试。

## 0.17 拍照、多选、本机智能抠图与独立故事

拍照使用系统相机和私有 CameraProvider；Android 13 及以上使用 Photo Picker，一次最多 20 张，较旧系统使用支持多选的文档选择器。WASM 引擎及 U²-Net small 模型随安装包提供，照片不发往外部推理服务。五只猫按性格分别拥有十个独立故事，五张原插画保留，新增 45 张独立画面。旧收藏继续读取原画，新增收藏不重复，最多十张。

编译、APK v2/v3 签名、101 个本地资源及 12 个路由案例校验通过；浏览器实测一次导入两张并完成本机抠图。安卓系统相机、原生照片选择器和飞行模式尚需实机验收。SHA256：17AD7C9F13FA6EC5758E6D720715F17997F05FE2AAB3F3FB8DB9597068828133。

## 0.18 联网与私密云备份

恢复 INTERNET 权限，仅放行现有秒悟项目 /cloud/ 的 HTTPS 接口，外部页面仍交系统浏览器打开。用户名密码登录，主动首次备份后自动上传快照；每台设备保留 3 份，换手机可手动恢复并保存恢复前副本。应用界面、字体、插画和本机抠图模型继续随 APK 提供。详见 docs/安卓版联网与云备份使用说明.md。
