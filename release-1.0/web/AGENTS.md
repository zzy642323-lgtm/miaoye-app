# 小猫与贴纸素材规则（用户要求长期保留）

用户指出小猫和贴纸经常裁切不准确。修改这些页面时必须复用以下规则，不能按页面尺寸重新估算素材坐标。

## 小猫

- 原始透明动作图：`assets/cat-actions-v22.png`，尺寸为 1374 × 1145，五只猫、每只六个动作。不要重新生成或更换这张原始图。
- 唯一绘制入口是 `record-art.js` 的 `RecordArt.catArtHtml` / `RecordArt.paintCat`。所有动作使用该文件内已校准的 `catRects`。
- SVG 使用外层适配显示尺寸、内层按源素材坐标裁切的双层结构。内层必须设置 `overflow="hidden"`，避免等比缩放后的留白区域露出相邻小猫或动作。仅设置外层 viewBox 不足以裁切整张动作图。
- 打印画板使用 `paintCat`，按同一 source rectangle 绘制，并保持猫咪原始比例。
- 各页面的小猫外观、名称从 `RecordArt.adopted()` 读取；数据键为 `miaoye-preview-adoption`。首页、好友吐槽、我的主页/小屋、制作页动作选择均跟随领养结果，不得写死“奶油”或猫编号 0。
- 已发布手账中的小猫是作品的一部分，不自动重写历史作品。

## 照片与装饰贴纸

- 照片素材必须是真正透明的抠图素材，不以圆角照片、CSS 遮罩或原图背景冒充抠图。
- 原始装饰图使用 `assets/stickers-v14.webp`，按 3 × 3 图集分格，预览与打印使用相同位置。不得露出邻格内容、拉伸主体或用 emoji 替代。
- 白边是用户明确要求保留的视觉。记录页照片默认调用 `RecordEngine.whiteBorder(base, 'line')`；除非用户主动选择无白边，不要移除。重新选择边框必须从原始透明 base 生成，避免重复叠边。
- 页面里的原有 cutout 素材和白边效果应保持；不要用旧的整张 JPG 覆盖透明素材。

## 验证

- 改绘制逻辑后检查领养卡片、首页、好友浮窗、小屋和制作页，并检查打印画板。
- 小猫的耳朵、尾巴、脚不能被切掉；不能露出邻近动作；透明背景不能变黑或带矩形底色；白边不能消失。
- 验证时保留用户已经领养的小猫和记录，不清空本地存储。

## 好友叠卡与小票（后续修正须保留）

- 好友卡片必须始终保留完整内容和自然高度。使用完整卡片互相遮挡实现层叠与抽出，禁止用缩短卡片高度或 `overflow:hidden` 来模拟折叠。
- 新增卡片后继续按索引交替左右偏移、轻微倾斜和循环配色；不要只给前四张写固定样式。
- 最后一篇完整展示，下方显示“我也是有底线的喵~”；给结束文案、小猫浮窗、底部导航分别留出位置。
- 自己发布的好友手账详情可删除，并能撤销；好友的记录不提供删除按钮。
- J 模式文件夹照片至少露出一半。“全部 N 页”快捷入口已经被用户要求移除，保留内容总览和管理本子。
- 打印小票右侧不得被容器裁掉。底部短句保持单行，按宽度适配字号；不能再次自动折成两行。

## 弹窗、文字手账与小猫性格
- 日历搜索在当前页面打开详情，切换搜索结果不切到内容总览；关闭详情保留日历、日期范围、搜索词和滚动位置。
- 日期区间弹窗只有点击应用才提交，取消或 Escape 必须恢复原范围和月份。
- 纯文字简单手账使用文字便签预览，不渲染空 src、数字图片地址或假照片；好友卡片移除空照片区，不预留照片高度。
- 手账编辑必须复用原 id、日期和创建时间，保存替换原记录而不是新增，更新时间供首页排序使用；编辑草稿不得覆盖新建草稿。
- 小猫性格沿用原版 app-v1.js：奶油温柔陪伴、橘子美食探险、墨墨安静守护、栗栗好奇收藏、糯米害羞暖心。统一通过 cat-voice.js 生成主题与性格回应。
- 已知贴纸按 sample / 素材标签识别主题；文字使用本地内容规则。任意上传照片语义识别尚无服务，不可宣称已识别图片内容。
- 我的主页展示小猫解锁列表与「敬请期待新朋友」占位卡，不恢复猫咪小屋。

## 自由看板与制作页交互（2026-10-11）
- F / J 的界面名称分别为自由（默认）和标准，内部 f / j 值保持兼容。
- 自由看板文字点击编辑，长按拖动，松手保存；文字位置单独存储，不改动照片随本子走的规则。
- 制作页一屏显示，底部不再显示小猫吐槽；素材上的叉号只删当前画板实例，不删除照片库。
- 制作页照片、文字长按编辑；拖动超过阈值取消长按。加页、删页、一键排版可撤销。底纸同步整篇所有页。
- 文字提供严肃、可爱、平静，画板和打印使用同一字体选择。小猫素材面板列出全部已解锁小猫。
- 上传可取消自动抠图，按用户要求保留原照片。照片编辑提供重抠、手动擦除/恢复与画笔大小；白边从 base 重新生成。
- 点点白边使用平滑白底加细点装饰，不能恢复断裂的粗点锯齿效果。
- 首页展示可继续编辑的草稿并标注草稿，打印成功后清除；好友已读清除动态 +1，待处理申请在好友列表显示 +1。
- 手账详情顶部关闭控件保持可见。旅行详情需一屏完整显示，无可见滚动条。
