# 喵页：云端管理与联网服务说明

核查日期：2026-10-05。免费额度和优惠可能调整，开通前以官方控制台为准。本说明是接入方案，当前版本尚未开通用户云同步。

## 建议先做什么

第一步保留现在的秒悟网站和 Android 本机手账，增加“可选的账号与私密云备份”。建议先用 Supabase 免费版做小范围测试；如果主要使用者在中国大陆，先测试手机网络下的登录与照片上传速度，再决定是否改用腾讯云 CloudBase。暂时不需要同时注册所有平台。

本机功能继续不依赖账号：拍照、多图导入、抠图、编辑、故事收藏。联网功能可以逐步增加：换手机恢复、手机与电脑同步、后台更新故事、版本公告、用户主动提交的问题反馈。

## 推荐的最小接入方案

**秒悟继续发布前端 + Supabase Free 负责登录、数据库和私密照片。** 先让少量测试用户使用，记录上传速度、成功率、每人存储量和每月流量，再决定是否扩容。已有 50 张猫咪海报随应用提供，避免每次向 AI 重新生成；本机抠图也避免按照片支付云端推理费用。

1. 创建一个免费 Supabase 项目，选择适合使用者的区域。
2. 建立 `profiles`（用户资料）、`notebooks`（本子）、`entries`（手账与版本）、`assets`（照片路径与归属）、`cat_collections`（故事收藏）表。
3. 每张私人记录包含 `user_id`，启用行级访问规则，使登录用户只能访问自己的数据。管理员管理公共故事、版本和公告，不默认浏览用户私人照片。
4. 照片使用 private bucket，通过短期签名地址读取；公开插画使用独立公开目录。不要把原图的 base64 塞进数据库。
5. 应用先保存本机草稿，联网后上传压缩图和变更。断网、账号退出或上传失败时仍可编辑；清楚显示“仅本机 / 待同步 / 已同步”。
6. 同时编辑同一篇时保留两份冲突副本，允许用户选择，避免最后一次上传悄悄覆盖另一设备的内容。
7. 提供手动备份、换设备恢复、注销账号和删除云数据入口。免费方案应定期导出数据库；同步不能代替可恢复的备份。

使用邮箱登录时，还需核实认证邮件发送限制与 SMTP 配置；短信验证码通常涉及单独费用，试用阶段可先不接短信。

## 后台可以管理哪些内容

| 管理内容 | 可提供的操作 |
| --- | --- |
| 50 张猫咪故事海报 | 按猫咪、故事编号查找；更新公开文字；上架新增版本；保持已收藏版本可读取 |
| 应用版本 | 发布 Android 安装包、更新说明、最低支持版本、校验值；提供旧版回退下载 |
| 用户使用情况 | 查看匿名数量、上传失败率、存储用量和反馈；避免记录照片内容与手账正文到日志 |
| 数据维护 | 定期导出备份；测试恢复；删除已注销账号的数据；清理上传后未引用的文件 |
| 公告与反馈 | 发布维护公告；接收用户主动提交的错误描述；截图上传需由用户选择 |

管理后台须使用单独管理员角色。数据库管理密钥和对象存储密钥只放在服务器配置中，不能进入网页、APK 或 GitHub。客户端可以使用权限受限的公开项目参数，但所有数据权限仍由服务器规则检查。

## 免费额度大概够多少照片

以下只是规划估算：假设每张压缩照片平均 300KB，1GB 文件存储约能放 3,000 张左右；如果同时保留原图、抠图和预览，数量会减少。20 位测试者每人 120 张已约 720MB，因此应先控制上传大小，展示每人已用容量，并在额度附近停止新增云上传、保留本机记录。下载和多设备同步还会消耗出站流量，不能只看存储量。

免费试用阶段建议：先备份压缩图，原图留本机；图片去重；一次同步只上传变化；公开海报缓存；用量接近额度时提示。保持 Free 套餐，不自动升级，任何付费计划都先明确费用。

## 分阶段实施与验收

| 阶段 | 完成内容 | 可验证的结果 |
| --- | --- | --- |
| 当前本机版 | 拍照、多图导入、本机抠图、独立故事海报 | 不登录也能编辑和导出；Android 相机和多选需要实机验收 |
| 免费云试用 | 登录 + 私密备份 + 恢复 | A 用户不能读 B 用户数据；断网不丢草稿；在另一设备恢复同一篇 |
| 日常管理 | 公共故事目录、版本公告、反馈和用量 | 旧收藏可读；公开目录不泄露私人照片；接近限额有提示 |
| 稳定使用 | 冲突处理、备份恢复、迁移与删除 | 恢复演练成功；账号删除可验证；超额策略明确 |

主要平台不需要一次全部接入。先完成本机体验，再以一个后端验证云备份，成本和排查难度都会更容易控制。
