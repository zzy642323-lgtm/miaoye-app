# 喵页 0.19 安卓版联网与云备份

已接入当前喵页秒悟项目的 Supabase Auth、PostgreSQL 和私密 Storage。2026-10-07 查询账号权益为免费体验版：1 个云服务、合计 1 GB 数据存储。没有购买套餐；本版没有 AI 云调用，也不使用邮件或短信验证码。额度和政策以后可能变化，以秒悟账号页面为准。

下载：https://s7ianzbg94fw.meoo.run/android.html

## 第一次使用

1. 下载 0.19 安装包，直接覆盖旧版。不要卸载或清除数据，否则旧版本机手账会被删除。
2. 联网后点右上角「云端备份」，填写用户名与密码并注册。用户名为 3—32 位英文字母、数字或下划线，不区分大小写；密码至少 8 位。这里是喵页云账号，与秒悟平台管理账号分开。
3. 点击「备份本机手账并开启自动备份」。这是首次上传授权；仅登录不会上传本机照片。
4. 看到「最近备份」时间后，点击「查看云端备份」检查日期和手账数量。

不需要向开发者提供密码、验证码或私人照片。请保存好用户名和密码；当前免费密码登录方式不支持通过邮件找回密码。

## 会备份什么

手账本、全部已保存手账及其内嵌照片、当前草稿、猫咪名字、成长、故事进度、已解锁照片进度和本子删除状态。内置插画、抠图模型和安装包无需每次上传；它们已随应用提供。已有插画没有重新生成或替换。

所有编辑仍先写入手机原有 IndexedDB 数据库。开启自动备份后，停止编辑约 30 秒会上传一个完整快照；离线失败不会删除本机内容，收到联网事件或下次保存、启动时会重试。可以手动立即备份或暂停自动备份。退出账号保留本机手账并暂停自动备份。

## 换手机与恢复

在另一台手机安装新版，用同一个喵页用户名登录，点击「查看云端备份 / 换手机恢复」，选择一份备份并确认恢复。

恢复会替换当前设备的手账。确认前会显示备份时间、篇数；恢复前会在本机保留一份副本，可以从备份列表里的「恢复本机的恢复前副本」撤回。恢复后自动备份暂停，检查内容后再主动开启。

每台设备保留最近 3 份快照，设备之间分别存储，不会自动覆盖另一台设备的内容。这是备份与手动恢复方式，当前不做两台设备同时编辑的实时合并。

## 存储限制与隐私

项目免费空间合计 1 GB，不是每个账号各有 1 GB。单份完整快照上限 50 MB；超过上限会提示，本机内容仍保留。完整快照包括照片，数据较多时优先使用 Wi-Fi；后续可以再升级为照片去重与增量同步。

备份索引表开启 RLS，只允许当前用户访问自己的记录；文件桶为私密桶，路径首段必须是本人用户 ID。网页和 APK 不包含 Supabase 服务端管理密钥。服务端代理使用公开 anon key 加当前用户 JWT，不能绕过 RLS；不允许代理管理员接口和任意外部地址。安卓仅放行当前秒悟项目的 HTTPS 云接口，界面和本机抠图模型继续来自应用内资源。

秒悟云端管理入口：https://meoo.com/chat/s7ianzbg94fw

管理员可在项目云服务面板查看数据库和存储用量；这是管理员权限，与普通 APP 账号权限不同。
