# 0.22 头像、昵称与好友动态

下载 https://s7ianzbg94fw.meoo.run/android.html 的 0.22 测试包，使用原签名覆盖安装，不要卸载或清除数据。

五只小猫和六种动作按本次提供的纸感水粉参考图对齐。界面和导出的手账使用同一份形象与主体边界，保留耳朵、尾巴和比例，不再依赖统一格子裁掉边缘。原有 50 张故事海报保留。旧导出图片不会被改动，手账里放置的小猫贴纸会在重新打开和导出时使用新版形象。

登录云账号后进入底部「好友手账」，能看到自己和双方同意的好友主动分享的动态，按「今天动态、全部动态、我的动态」查看。页面顶部展示自己与好友头像，并有「＋ 加好友」按钮。添加好友仍使用喵页登录用户名，需对方同意。

点击好友头像进入备注编辑。备注最多 20 个字，留空保存可清除；备注只对设置者可见，存储在自己的云账号下，好友、被备注者和其他账号都无法查看。备注显示在你的好友列表和动态中。点击自己的头像可进入云账号设置。

右上角「云端备份」→「编辑我的头像和昵称」，可以选小猫头像或从相册上传自己的头像，填写昵称并保存。头像照片先在设备上裁为方形 128×128 小图，点击保存才上传；不会上传原照片。原图限制 10 MB，保存头像只接受 JPEG/PNG 小图，拒绝 SVG 和第三方网址。昵称最多 20 个字，修改昵称不改变登录用户名、密码或原有手账。

头像、昵称会显示在好友动态和好友申请中。只有主动确认分享的一页图片进入动态，其他手账、照片库及私密备份继续保持私密。

开发说明：新增 `meoo/migrations/social-profiles.sql`，使用用户权限受限的 RPC 接口读写公开名片和本人私密备注，不向客户端暴露管理密钥。备注表禁止客户端直接读写；写备注必须仍为双方同意的好友。数据库事务测试覆盖陌生人、跨账号备注、移除好友及不安全头像，测试数据回滚。


好友页新版采用纸质手账卡片。顶部默认为「全部」，展示自己和好友的已分享动态；头像轨道仅包含已接受的好友，隐藏滚动条，直接左右滑动。滑到好友时显示其备注或昵称，并筛选对应动态，点击头像编辑私密备注。好友有尚未查看的新动态显示红色 +1，查看该好友后消除；已读记录按当前云账号存于设备，其他设备独立记录。+1 为有更新的提示，不是未读数量；当前打开页面需重新进入才能获取新发布。原今天／我的／全部动态三个筛选按钮已移除。
