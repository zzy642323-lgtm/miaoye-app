# 喵页 0.21 更新与秒悟账号说明

## 安卓更新

从 https://s7ianzbg94fw.meoo.run/android.html 下载 0.21 测试版，覆盖安装。不要卸载或清除数据，以免丢失本机手账。浏览器版本刷新后即可使用独立好友页面；原生 HTTPS 通道需要安装新 APK。

本机抠图改为清除低置信度背景、收紧模糊边缘、补齐主体内部的小缺口，并去除极小的独立噪点。较大的镂空区域（例如杯把）会保留。复杂毛发、玻璃和与背景颜色接近的物品仍可能需要手动修边；已有照片贴纸不会自动改变，可以在编辑页选择「重新抠图」。所有现有猫咪和故事插画保持原样。

底部导航现在为「我的手账、日历回顾、好友手账、猫咪小屋」。首页仍可以创建当天手账。「好友手账」独立显示今天或最近的分享，可以添加好友、同意申请、分享一页、点赞、取消点赞和撤回分享。分享仍需明确确认，且仅双方同意的好友可见。

## 云连接

旧版网络失败会统一显示“手机暂时连接不上云端”，这不能证明手机没有联网，也不能区分 WebView 请求、DNS、TLS 或服务器超时。0.21 安卓版通过受限的原生 HTTPS 通道请求现有秒悟云接口，避免依赖 WebView 跨域请求；浏览器版继续正常使用网页请求。

原生通道仅接受本应用固定 HTTPS 域名的 `/cloud/` 路径，验证 TLS 证书，拒绝重定向和其他域名。密码仅用于当前认证请求，不保存到本机；仍保存用户自己的登录令牌。数据库和图片的权限仍由现有用户认证和访问策略控制，没有把管理员密钥放入 APK。

新版会区分用户名/密码错误、请求过频、响应超时、证书失败和地址解析失败。遇到超时先稍后重试，本机手账仍保留。若仍失败，请提供新版报错原文、手机型号、安卓版本及 Android System WebView 版本，便于进一步定位。编译、签名和自动化检查不能替代安卓实机联网验证。

## 秒悟账号和邀请积分

喵页当前使用秒悟云服务提供的独立应用用户认证。个人秒悟平台账号用于管理项目和平台权益；公开文档中尚未找到可直接用于喵页用户登录的个人秒悟 OAuth 接口。不能把平台管理令牌或 CLI 登录凭证交给下载者。未来若秒悟提供正式应用登录接口，可以另行接入；目前保留喵页云账号。

秒悟官方邀请规则要求新用户通过有效邀请链接/邀请码首次注册秒悟并完成必要验证，奖励还受平台审核和活动规则约束。下载喵页 APK、注册喵页云账号或添加喵页好友，本身不等于注册秒悟，也不能自动算作平台邀请。

如果希望提供官方邀请入口，可从你的秒悟账号复制真实邀请链接，另行放在下载页，让用户明确选择访问秒悟。不能承诺每次下载都会获得积分；链接有效期和奖励以秒悟活动页为准。
