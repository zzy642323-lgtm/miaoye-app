# 五只猫的独立故事海报

- 原有 `web/assets/adventure-0-v8.webp` 至 `adventure-4-v8.webp` 完整保留，SHA256 与此前 GitHub 快照一致。
- 新增 45 张独立画面使用内置 ImageGen 生成，PNG 原稿保存在 `posters/`，应用使用同名 WebP。
- `poster-catalog.json` 定义每只猫的十个故事、正文和画面内容；`generation-manifest.json` 保存新增图的生成提示词。
- 奶油：温柔慢热；橘子：热情贪吃；墨墨：安静勇敢；栗栗：活泼好奇；糯米：害羞黏人。每只猫的故事不同，不以同一图片换文案代替新增海报。
- 风格依据用户上传的平涂、纸张颗粒、蜡笔和不透明水粉参考图，以及用户满意的原画。
- `scripts/prepare-posters.py` 仅编码 PNG 为 WebP 并制作验收缩略图，不重绘原画。

第一张新增图（奶油 / 把小花带回来）提示词：以奶油原画为严格风格与角色参考，新增完整竖版 1024 × 1536 画面；小只纤细奶油白猫、绿色杏仁眼、细金色项圈，嘴里叼着被风吹落的粉色小花，走过花园小路，背景为青绿门与珊瑚色花盆。毛色使用平涂奶油色块，不画细毛；不透明水粉、剪纸般色块、干蜡笔纸张纹理、极少明暗。不得加入文字、水印、边框或拼图，不得写实或立体渲染。生成后另存为 `posters/adventure-0-2-v9.png`，不覆盖原画。
