# 喵页 v2

简洁可爱的猫咪照片手账，支持批量照片、自动柔和调色、本机 AI 抠图、实际透明 PNG 白边、多本手账、多页画布、直接拖动缩放/双指捏合、撤销、关键词素材匹配和图片导出。

## 使用

一次选择最多 20 张，每篇最多 120 张素材、50 页。默认每页 4 张。照片名字和标签可以与文字匹配，咖啡、旅行、上学、上班等词会添加相应装饰。照片不做语义识别。抠图首次下载模型较慢，失败会明确提示并保留原图。

不登录可在当前浏览器体验并自动保存草稿；登录 ChatGPT 后，保存的本子、手账、照片和猫咪成长私密同步。仅手动发布的碎碎念按所选好友/世界范围分享。好友码相互确认后可看到好友动态、点赞和评论。公开链接允许朋友打开预览，不自动公开私密手账。

猫咪按不同原始照片累计解锁：奶油 0、橘子 3、墨墨 8、栗栗 15、糯米 25。示例和重复保存不计数。3/7 天不记录时仅温柔问候，没有喂养或断签惩罚。

## 开发和验证

- `node server-v2.mjs`：127.0.0.1:4174 本地访客预览。
- 本地测试可设置 MIAOYE_LOCAL_AUTH=1，`?tester=friend` 切换测试朋友；此模拟身份仅存在 Node 本地适配器，生产 Worker 无此入口。
- `node tests/worker.test.mjs`：数据库隔离、照片归属、原图去重计数、好友确认、动态可见范围和跨站提交测试。
- `node scripts/build.mjs`：生成 Cloudflare Worker 与发布元数据。
- 数据层：Sites D1 + R2，Drizzle 生成 SQL 迁移。生产身份只接受平台转发的已验证用户头。

已有第一版的浏览器记录及未完成草稿会迁移到新版结构；本机数据不会自动发送到云端，需要登录并保存。


## v4 编辑器与回顾

编辑页固定画布，照片/文字/猫咪/页面设置使用抽屉和弹窗。站酷快乐体文字贴纸支持圈圈、点点及底色，最多 60 字、6 行。每只猫六种动作，前端与保存接口均校验解锁。日历提供每日、每周与年度概览，可从照片素材选择日期标记。公开访客可本机使用；私密云同步与好友互动仍需登录。运行 `node tests/worker.test.mjs` 和 `node tests/editor-v4.test.mjs` 验证。
